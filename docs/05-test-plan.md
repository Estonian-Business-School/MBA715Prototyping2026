## Facilitator script
1. **Welcome (2 min):** thank them, explain that you test the product, not them; ask them to think aloud; ask consent to record.
2. **Background (2 min):** "Tell me about how you handle [problem] today."
3. **Tasks (15 min):** read each scenario; do not help; ask "What are you looking for?" when they hesitate.
4. **Questionnaire (5 min):** SUS / UEQ-S and reaction cards.
5. **Wrap-up (3 min):** "What would make you pay for this?" · "What is missing?"
